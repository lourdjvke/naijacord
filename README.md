# NaijaCord

A mobile-first community and messaging SPA prototype built with React, Vite and React Router.

## Development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
```

Deploy the `dist` directory to Cloudflare Pages. The `public/_redirects` file enables SPA route fallback.

This prototype uses mock data and local browser storage. Video calls are UI simulations; no real media stream or backend is connected.
